当前阶段（如实说明）

  • 这一版只把 ask() 的最终文字答案接到浏览器上。
  • 模型中途调了哪个工具、写了什么 SQL、有没有自我修正——现在拿不到，所以界面不显示，也不假装有。
  • 不支持"停止运行"和"改 SQL 重跑"：当前 agent 是一次同步调用，要支持就得先改 agent 的循环。
  • 服务是单线程的，一次只能问一个问题：07_tools.py 的 sqlite 连接建在主线程，跨线程会报 ProgrammingError。这是当前代码的真实约束，不是界面偷懒。

这份数据里两个真实的坑

  • "退货"和"取消单"其实是同一件事。顾客退货全部走 C 开头的发票；那 3,393 条非 C 的负数量行 Price 全为 0，是库存调整（报损、赠品），不是退货。
  • 做商品维度必须排除非商品代码： POST DOT M C2 D S BANK CHARGES ADJUST，否则快递费和手续费会排到"最畅销商品"第一。
